Block randomization

Illustration

Estimator

\[\widehat{ATE}_{\text{Block}} = \sum_{b=1}^B \frac{n_b}{N} \widehat{ATE}_b\]

Code

# Standard design
lm(Y ~ Z, 
   data = data)

# Block randomized
lm(Y ~ Z + block, 
   data = data)
